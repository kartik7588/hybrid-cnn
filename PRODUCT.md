# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Breast imaging frontend demonstration with scan upload, sample predictions, patient history, reports, analytics and local preferences.

## Capabilities and Constraints

Preserve the existing routes and interactions. Use Vite, React, Tailwind and existing dependencies. No clinical backend, authentication service, measured accuracy or validated inference is present. Never present illustrative values as clinical evidence.

## Brand Commitments

The user requested a restrained clinical interface, neutral surfaces, readable typography, subtle dividers and a teal accent. Status colors must have semantic meaning.

## Accessibility

Keyboard operation, visible focus, accessible labels, reduced motion and responsive layouts are required. Theme changes must preserve state.
